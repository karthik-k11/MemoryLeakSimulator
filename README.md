# MemoryLeak Simulator

### Python Memory Analysis Laboratory

MemoryLeak Simulator is a lightweight local tool for creating controlled Python memory experiments and analyzing memory usage over time.

The project is designed as an educational laboratory for understanding:

- Memory allocation
- Memory growth
- Object retention
- Garbage collection
- Reference cycles
- Python memory behavior

> Memory growth does not automatically mean a memory leak.

The project will be developed progressively from Basic → Intermediate → Advanced.
